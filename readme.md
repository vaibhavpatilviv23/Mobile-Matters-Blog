# 📱 Mobile Matters Blog

Mobile Matters is a technology blog focused on smartphones, gadgets, technology news, reviews, specifications, and buying guides.

The website is built as a lightweight static website using HTML, CSS, JavaScript, and Tailwind CSS, with deployment handled through Netlify.

## 📸 Image Optimization

To improve performance and reduce bandwidth usage:

- All images are converted to WebP format.
- Images are organized by category and article.
- Descriptive filenames are used for improved maintainability.
- Lazy loading is implemented where applicable.
